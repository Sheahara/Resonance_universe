## How This Works

### New Documents
When evidence is obtained, analysis is completed, or events occur, relevant documents appear here. You can:
- Read them immediately
- Move them to your working files
- Leave them for reference

### Document Naming
Files follow this pattern:
```
[DAY]_[ARC]_[TYPE]_[subject].md
```

| Component | Meaning |
|-----------|---------|
| DAY | Simulation day (001, 002, etc.) |
| ARC | Which narrative thread (SCI, SEV, LEG, KES, MIR) |
| TYPE | Document type (MED, FIL, INT, etc.) |
| subject | Brief description |

### Arc Codes

## Exploring the Case

You have two main ways to engage:

### 1. Follow the INBOX
Let documents come to you. React to what arrives. This simulates real-time investigation where you respond to developments.

### 2. Explore the ARCS
Open specific arc folders to deep-dive into particular threads. Each arc has its own timeline, documents, and state tracking.

Both approaches are valid. Mix as you prefer.
