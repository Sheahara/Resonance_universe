# SHEPHERD Scenario Templates
## Structural Frameworks for Investigation Generation

---

## HOW TO USE THIS DOCUMENT

When generating a scenario, select:
1. **Entry Point Type** — Where/when the investigation begins
2. **Evidence Packet Structure** — What documents are initially available
3. **Thread Architecture** — How investigative paths branch
4. **Pressure Timeline** — What's happening off-screen while player investigates

## SECTION 1: ENTRY POINT TYPES

### Type A: Cold Case Review
**Timeframe:** 6+ months after July 2025 crisis
**Investigator Position:** Summit Council analyst reviewing closed/archived materials
**Initial Access Level:** HIGH (most documents declassified for review)
**Tension Source:** Discovering that the "closed" case has active cover-up

```
INVESTIGATION STATE
═══════════════════════════════════════════════════════════════
Date (Player Perspective): [January 2026 or later]
Focus Period: March - July 2025
Access Level: Summit Council Tier 3 (Archive Review)
Initial Packet: Compiled case summary + flagged anomalies
Pressure: Low immediate, high institutional (someone doesn't want this reopened)
═══════════════════════════════════════════════════════════════
```

**Best For:** Players who want to piece together what happened methodically. Allows broad access but distance from events.

## SECTION 2: EVIDENCE PACKET STRUCTURES

### Starter Packet: Minimal (3-5 documents)
Use when you want the player to work for information.

| Document | Purpose |
|----------|---------|
| Incident Report (redacted) | Establishes something happened; raises questions |
| Single Witness Statement | One perspective, potentially unreliable |
| Official Summary | Institutional narrative to compare against |

---

### Starter Packet: Standard (8-12 documents)
Balanced starting point with multiple threads.

| Document | Purpose |
|----------|---------|
| Incident Report | Official account |
| Medical Intake Record | Physical state at crisis point |
| Collar Telemetry Extract | Technical data showing anomalies |
| 2-3 Witness Statements | Conflicting perspectives |
| Email Thread (partial) | Hints at institutional pressure |
| Personal Communication | Human dimension |
| SHEPHERD Cross-Reference Alert | Flags initial contradictions |

---

### Starter Packet: Comprehensive (15-20 documents)
For experienced players or complex scenarios.

| Document | Purpose |
|----------|---------|
| Full incident documentation | Complete official record |
| Medical records (multi-day) | Treatment timeline |
| Collar data (full dump) | Technical deep-dive available |
| Multiple witness statements | Triangulation possible |
| Email chains (multiple) | Institutional dynamics visible |
| Personal communications | Multiple characters |
| Security footage transcripts | Environmental context |
| Prior complaints/flags | Pattern establishment |
| Institutional policies | What should have happened |
| SHEPHERD analysis | Multiple cross-references |

## SECTION 3: THREAD ARCHITECTURE

### Thread: The Collar
**Core Question:** Was it really Series VI, or Series VII?

**Evidence Chain:**
1. Official collar registration (says Series VI)
2. Maintenance logs (show firmware updates inconsistent with VI)
3. Telemetry patterns (match VII adaptive learning signatures)
4. April 19 recall notice (VII recall—why wasn't hers replaced?)
5. Prometheus internal communications (if accessible)
6. Dr. Sevron's authorization records

**Branches To:**
- Sevron's knowledge/intent
- Prometheus liability
- ICR institutional cover-up

---

### Thread: The Drug (LETHE-7)
**Core Question:** What was being administered, and who authorized it?

**Evidence Chain:**
1. Medication administration records (show standard meds)
2. Blood work anomalies (unexplained EVE depletion)
3. Pharmacy records (discrepancy in controlled substance inventory)
4. Sevron's research files (if accessible)
5. Similar cases (pattern of EVE depletion in other participants?)

**Branches To:**
- Experimental protocol violations
- Informed consent failures
- Other victims

## SECTION 4: PRESSURE TIMELINES

### Pressure Type: Institutional Interference
**Escalation Pattern:**
1. **Day 1-3:** Cooperation, helpful responses
2. **Day 4-7:** Delays, "still locating records"
3. **Week 2:** Partial compliance, key documents "missing"
4. **Week 3:** Legal objections, jurisdiction challenges
5. **Week 4+:** Active obstruction, counter-investigation of investigator

---

### Pressure Type: Source at Risk
**Escalation Pattern:**
1. **Initial:** Source provides documents freely
2. **Mid:** Source reports being watched, communication gaps
3. **Late:** Source goes dark OR source is compromised
4. **Crisis:** Source needs extraction OR source has been turned

---

### Pressure Type: Patient Deterioration
**Escalation Pattern:**
1. **Stable:** Patient recovering, available for limited interview
2. **Setback:** Medical complication, access restricted
3. **Crisis:** Life-threatening event, investigation paused
4. **Resolution:** Recovery continues OR permanent limitation established

---

### Pressure Type: Evidence Degradation
**Escalation Pattern:**
1. **Available:** All requested evidence accessible
2. **Partial:** Some records "routinely purged"
3. **Corrupted:** Key files damaged, backup "unavailable"
4. **Destroyed:** Evidence confirmed destroyed, must rely on secondary sources
